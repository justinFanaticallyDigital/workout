PROTOCOL

Update rules

How this doc stays accurate as we work.

Updated every time we ship a screen.

  1. When a new file lands → its row's File column gets the filename, and status flips from Untouched → Skeleton / Explored.
  2. When a theme is picked + applied → row flips to Themed. Theme name goes in notes.
  3. When a cluster fully closes → progress bar to 100%, header note set.
  4. Every change adds a Change log entry below with date, screens touched, and one-line summary.
  5. The Currently working banner up top reflects the active cluster. Always 1 active cluster.
  6. Counts strip updates: total / themed / skeleton / explored / untouched / % complete.
  7. Order of operations is re-ordered as priorities shift — don't delete completed rows, mark them Done.
